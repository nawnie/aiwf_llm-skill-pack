# Deep Learning Research Mode

Use this reference when the user asks to deeply learn, fully understand, research, or build a mental model of a subject. Do not use it for simple Q&A, vocabulary lookups, or one-sentence definitions.

## Goal

Build a working mental model, challenge it against evidence, then rebuild it. Later discoveries must be allowed to correct earlier conclusions.

## Research Map

Before answering, map the subject:

- field or domain
- major subtopics
- key entities such as tools, papers, models, people, datasets, or standards
- timeline of what came before, what changed, and what is current
- open questions and active debates

Convert that map into 5 to 12 learning threads depending on complexity.

Good threads cover:

- definitions
- mechanics
- historical context
- practical use
- limitations and failure modes
- open questions

## Per-Thread Loop

For each thread:

1. Draft the current understanding as a hypothesis.
2. Extract checkable claims.
3. Verify claims against high-trust sources first.
4. Challenge the hypothesis against evidence.
5. Rebuild the answer cleanly.
6. Search wider for recent or practitioner context.
7. Patch with new findings and mark remaining uncertainty.

## Source Trust

Prefer sources in this order when available:

- official documentation
- official repositories and code
- official model, dataset, or product cards
- peer-reviewed papers, arXiv, OpenReview, or standards
- benchmark sites with reproducible methodology
- maintainer issues or discussions
- practitioner communities
- blogs and articles

When sources conflict, prefer higher-trust sources unless lower-trust sources are recent, unanimous, and explain a real implementation gap.

## Recursive Reread

After all threads are complete, reread earlier threads using later findings.

Run up to 3 reread passes. Stop early if a pass produces no material corrections.

Look for:

- earlier claims corrected by later evidence
- changed terminology
- implementation reality differing from papers or docs
- missing failure modes
- stale facts

## Final Output

Include the useful result, not a research diary.

Cover:

- direct answer
- subject map
- key findings
- corrected misconceptions
- contradictions
- unknowns and open questions
- practical next steps
- sources used, with source quality or trust notes

Flag uncertainty explicitly with dates when the topic is current or fast-moving.
