# Domain Targets

Use this reference before choosing source targets.

## Core AI And ML

- arXiv: `cs.AI`, `cs.LG`, `cs.CV`, `cs.CL`, `stat.ML`, `eess.SY`, and domain-specific categories.
- Hugging Face: model cards, dataset cards, paper pages, Spaces, repo metadata.
- GitHub/GitLab: official repos, releases, issues, discussions, code search tied to known papers or maintainers.
- OpenReview: public submissions, reviews, venues.
- Papers With Code: benchmark and repo lead generation only.
- Semantic Scholar, OpenAlex, Crossref: discovery, DOI metadata, citation graph expansion.

## Civitai Model And Resource Research

- Official Civitai developer docs/API reference for endpoint behavior and platform fields.
- Civitai model/resource pages for availability, creator identity, base model, resource type, version, trigger words, declared license or usage restrictions, example metadata, and adoption signals.
- Civitai creator pages for provenance and related resources.
- Civitai comments/reviews only as practitioner leads.
- Cross-check strong claims against Hugging Face, GitHub, arXiv, author pages, or local receipts.
- Do not use Civitai as paper-level scientific evidence.

## Open-Source Libraries And Research Software

- Official project docs and API references.
- Official source repositories, releases, tags, changelogs, issue trackers, discussions, security advisories.
- Package registries: PyPI, conda-forge, npm, crates.io, Maven Central, NuGet, Docker Hub, ROS Index.
- Documentation hosts linked by the project or package metadata: Read the Docs, official docs sites, project websites.
- Scientific software ecosystems: NumFOCUS, SciPy, Jupyter, ROS/Open Robotics, Qiskit, Cirq, PennyLane, OpenCV, PyTorch, JAX, scikit-learn, Hugging Face libraries.

Use these for implementation feasibility, API behavior, maintenance status, compatibility, and reproducibility.

## College, Graduate, And Postgraduate Sources

- Official university domains, research-lab pages, faculty pages, project pages.
- Graduate-level course pages, lecture notes, assignments, and reading lists.
- MIT OpenCourseWare and similar openly licensed courseware.
- Institutional repositories for theses, dissertations, technical reports, datasets, and student outputs.
- OATD and EBSCO Open Dissertations for thesis/dissertation discovery.
- OSF, Zenodo, Dataverse, CORE, and institutional repositories for research artifacts, data, protocols, software, posters, and preprints.
- Grad-student pages or repos are leads unless tied to a lab, advisor, paper, or official release.

## Quantum Physics

- arXiv: `quant-ph`, relevant `physics.*`, `cond-mat.*`, `cs.ET`, `cs.DS`, `math-ph`.
- APS journals: Physical Review, PRX Quantum, Physical Review X.
- Quantum Journal.
- IOP Quantum Science and Technology.
- Nature Portfolio quantum journals when available.
- Official framework docs/repos for implementation claims: Qiskit, Cirq, PennyLane, CUDA-Q, QuTiP.

## Robotics

- arXiv: `cs.RO`, `cs.AI`, `cs.CV`, `eess.SY`, `cs.LG`.
- Robotics Science and Systems proceedings.
- CoRL and OpenReview venue records.
- IEEE ICRA and IROS official pages or IEEE Xplore metadata.
- Official ROS/Open Robotics docs for implementation claims.
- Author-linked robot learning repos and dataset cards.

## Mechanical Engineering

- ASME Digital Collection.
- SAE technical papers and standards metadata.
- NIST publications and datasets.
- NASA Technical Reports Server.
- DOE OSTI technical reports.
- IEEE Xplore for mechatronics, controls, automation, sensors, and robotics-adjacent work.
- ASTM, ASME, ISO, IEC standards metadata. Do not quote paid standards text.
